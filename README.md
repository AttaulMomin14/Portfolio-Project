# Portfolio-Project
Adventure Works Power BI Dashboard

The management team needed a way to track KPIs, compare regional performance, analyze product-level trends, and identify high-value customers. I developed a comprehensive 4-page Power BI dashboard which resulted in a 30% reduction in data analysis time and enabling real-time monitoring of KPI's.

The end result was a fully interactive and insightful dashboard for a bike selling company, which the management used to take data driven decisions.

I was given folder of raw csv files, which contained information about transactions, returns, products, customers and sales territories.

I used Power BI to
- Connected and transformed the raw data using Power Query.
- Build a relational data model in Power BI.
- Created calculated columns and measures with DAX to answer business questions.
- Designed an interactive dashboard to visualize data.
